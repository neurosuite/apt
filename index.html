Neurosuite apt repository

Packages of NeuroScope, Klusters, NDManager and the NDManager plugins for Ubuntu 24.04 and newer (amd64).

Setup

sudo install -d /etc/apt/keyrings
sudo curl -fsSL -o /etc/apt/keyrings/neurosuite.asc https://neurosuite.github.io/apt/neurosuite.asc
sudo tee /etc/apt/sources.list.d/neurosuite.sources >/dev/null <<'END'
Types: deb
URIs: https://neurosuite.github.io/apt
Suites: noble
Components: main
Signed-By: /etc/apt/keyrings/neurosuite.asc
END
sudo apt update
sudo apt install neuroscope klusters ndmanager ndmanager-plugins

Release candidates are in the testing component. To get them, use Components: main testing.

The repository is rebuilt from the GitHub releases every night. Other ways to install the applications are listed on neurosuite.github.io.
